# llms.ink for Hermes Agent

```sh
hermes plugins install lukax/llms-ink-skills/hermes --enable
```

The llms.ink skills, as `llms-ink:<skill>`, and the remote MCP server https://llms.ink/mcp. For an API key, see the Hermes section of [../README.md](../README.md#install).

Generated from the repository root by the llms.ink sync script (the same skills without their OpenClaw metadata, which Hermes rejects): edit the root files, not these.
