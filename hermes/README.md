# llms.ink Agent Plugins package

For Hermes Agent and GitHub Copilot CLI:

```sh
hermes plugins install lukax/llms-ink-skills/hermes --enable
copilot plugin marketplace add lukax/llms-ink-skills
copilot plugin install llms-ink@llms-ink
```

The llms.ink skills and the remote MCP server https://llms.ink/mcp. For an API key, see [../README.md](../README.md#install).

Generated from the repository root by the llms.ink sync script (the same skills without their OpenClaw metadata, which Agent Plugins clients reject): edit the root files, not these.
